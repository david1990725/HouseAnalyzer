# 住得明白｜AI Rental Property Analyzer 原型

可安裝的繁體中文 PWA，依據 V3 部署計畫呈現租屋物件的客觀分析流程。

## 已涵蓋

- AI 客觀總評與交通、學區、空間／屋況、周邊環境四面向
- 現在的優勢／問題、具可信程度的未來機會／風險
- 最大交換條件、適合與不適合的生活情境
- 與 AI 評價獨立的「我的喜好」、看房筆記與最終決策
- 主觀資料僅儲存在瀏覽器 `localStorage`，不會影響客觀分析
- 使用者自行輸入 OpenAI API Key（BYOK），Key 只保留於本次瀏覽器工作階段
- `/api/analyze` 只接收客觀物件資料與當次 API Key，伺服器不保存金鑰或主觀心得
- 安裝後可離線開啟介面與繼續編輯本機筆記；AI 分析仍需要網路

## 預覽

在此目錄執行以下命令，可啟動同時支援 PWA 與 `/api/analyze` 的本機開發伺服器：

```sh
npm run dev
```

然後瀏覽 `http://127.0.0.1:3000`。

## 使用 AI 分析

1. 點選「編輯客觀資料」，確認會提供給 AI 的物件資料。
2. 點選「AI 設定」，填入自己的 OpenAI API Key 與模型。
3. 點選「用 AI 重新分析」。

目前未整合地圖、租金行情或其他公開資料搜尋；AI 只會依據使用者輸入的客觀資料，並在資訊不足時提示待確認事項。
